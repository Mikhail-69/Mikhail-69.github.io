## 1. Веб-страницы

Каждая страница работает без перезагрузки: тега `form` нет, кнопки имеют
`type="button"` и вызывают JavaScript. Текст из базы вставляется через
`textContent`, поэтому HTML из записей не исполняется.

Локальный запуск:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

### 1.1. Supabase

1. Зарегистрируйтесь на https://supabase.com и создайте проект.
2. Откройте SQL Editor и выполните скрипт:

```sql
create table if not exists public.students (
    id bigint generated by default as identity primary key,
    name text not null,
    specialty text not null,
    grad_year integer not null
);

-- Учебный режим: доступ без политик. Только для демонстрации!
alter table public.students disable row level security;

-- Подписка Realtime на изменения таблицы.
do $$
begin
    if not exists (
        select 1
        from pg_publication_tables
        where pubname = 'supabase_realtime'
          and schemaname = 'public'
          and tablename = 'students'
    ) then
        alter publication supabase_realtime add table public.students;
    end if;
end $$;
```

3. В текущей копии Project URL и publishable key уже указаны в
   `js/supabase-config.js`. Для другого проекта замените эти значения.
4. Откройте `supabase.html` и `supabase-realtime.html`.

Второй файл дополнительно подписывается на `postgres_changes` и показывает
журнал изменений. Проверить realtime можно в двух вкладках: добавьте запись
в одной — список во второй обновится сам.

### 1.2. Firebase

1. Зарегистрируйтесь на https://console.firebase.google.com и создайте проект.
2. Databases & Storage -> Realtime Database -> Create Database.
3. Project settings -> Your apps -> Web app: скопируйте `firebaseConfig`.
4. В текущей копии конфигурация указана в `js/firebase-config.js`. Для другого
   проекта замените значения из `firebaseConfig`; `databaseURL` должен совпадать
   со ссылкой из раздела Realtime Database.
5. Для учебной работы разрешите доступ к узлу `students` в правилах:

```json
{
  "rules": {
    "students": {
      ".read": true,
      ".write": true
    }
  }
}
```

6. Откройте `firebase.html` и `firebase-realtime.html`.

Обычная страница читает данные один раз (`once('value')`), realtime-версия
держит подписку (`on('value')`) и пишет журнал событий `child_added`,
`child_changed`, `child_removed`.

### 1.3. Безопасность

Настройки выше открывают базу на чтение и запись всем. Это допустимо только
для учебной демонстрации с вымышленными данными. Ключ `service_role` в Supabase
нельзя вставлять в сайт, коммитить или передавать третьим лицам. Для настоящей
регистрации используйте Supabase Auth или Firebase Authentication и не храните
пароли в открытой таблице.

## 2. Flutter-приложение

Приложение `College App` показывает список студентов и позволяет добавлять и
удалять записи (данные хранятся в памяти). Сборка:

```bash
cd flutter_project
flutter pub get
flutter run                 # запуск на подключённом устройстве или эмуляторе
flutter build apk           # debug APK
flutter build apk --release # release APK
```

Готовый файл: `flutter_project/build/app/outputs/flutter-apk/app-release.apk`.

Проверки:

```bash
cd flutter_project
dart analyze
flutter test
```

## 3. GitHub Actions

Workflow `.github/workflows/android-release.yml` запускается при push в `main`
и вручную через вкладку Actions.

Шаги: установка JDK 21 и Flutter, `flutter pub get`, `flutter analyze`,
`flutter test`, `flutter build apk --release`. Затем APK загружается как
артефакт workflow и прикрепляется к GitHub Release с тегом
`build-<номер запуска>`.

Скачать APK можно двумя способами:

- вкладка **Releases** репозитория;
- страница запуска workflow -> раздел **Artifacts**.

Для создания релиза workflow достаточно стандартного `GITHUB_TOKEN` с правом
`contents: write`, отдельные секреты не нужны.
