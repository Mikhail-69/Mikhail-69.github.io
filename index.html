Лабораторные: базы данных

Четыре страницы с одинаковым набором полей (имя, специальность, год выпуска): чтение и добавление записей в Supabase и Firebase, а также версии с обновлением списка в реальном времени.

  • Supabase: select и insert
  • Supabase Realtime: подписка на изменения
  • Firebase: select и insert
  • Firebase Realtime: подписка на изменения
  • Авторизация Google / GitHub с ролями

Мобильное приложение на Flutter лежит в папке flutter_project, готовый APK — в разделе Releases.
